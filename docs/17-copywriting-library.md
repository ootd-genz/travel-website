# Library Copywriting — Bahasa Indonesia

Tone: hangat, meyakinkan, jelas, tidak berlebihan, dan mendorong tindakan tanpa janji palsu.

## Brand Voice

- gunakan `kamu` untuk public copy agar terasa dekat;
- admin UI menggunakan bahasa operasional yang langsung;
- hindari jargon travel yang tidak perlu;
- harga, transfer, status, dan syarat harus sangat jelas;
- jangan memakai klaim `termurah`, `pasti aman`, `100%` tanpa bukti.
